# Live SERP observation protocol

## Record the context

- Query exactly as searched
- Country or market and language
- Device context when known
- Observation date
- Search or browser tool used
- Personalization, login, location, or rendering limitations

## Observe before interpreting

Record the visible result types and their order: organic results, ads, shopping, local pack, videos, images, discussions, featured snippets, answer modules, and AI-generated surfaces.

For relevant organic results, record:

- URL and domain
- Page type and apparent audience
- Publication or update date when visible
- Title and promise
- Major topics and entities covered
- Evidence type and conversion path

Do not treat `site:` estimates, snippets, or third-party keyword metrics as exact ground truth.

## Separate evidence types

- **Measured:** Values present in an authorized export or tool output.
- **Observed:** Qualitative facts visible in the current SERP or page.
- **Inferred:** Interpretation such as likely intent or content gap.
- **Hypothesized:** Idea requiring validation.

Label each recommendation accordingly.
